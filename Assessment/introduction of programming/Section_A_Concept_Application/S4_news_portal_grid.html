Global Chronicle News Portal

Responsive 3-Column Desktop & 1-Column Mobile Layout via Bootstrap 12-Column Grid

Bootstrap Grid Implementation Detail:

Each article column uses the class combination col-12 col-md-4. On mobile devices (< 768px), col-12 forces each item to occupy full 100% width (single column). On desktop/tablet screens (≥ 768px), col-md-4 forces each card to span 4 of 12 columns, yielding a clean 3-column grid (12 / 4 = 3) without custom media queries.
